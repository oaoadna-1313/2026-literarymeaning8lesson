## 💡 特色亮點

- **雙軌學習模式**：網站首頁提供「📖 詳解講義模式 (PDF)」與「✏️ 自練題目模式 (HTML)」即時切換。
- **純題作答模式**：初始狀態純呈現題幹與選項，無答案干擾，培養實戰做題直覺。
- **互動即時核對**：點擊選項即時給予答題回饋，綠色正解、紅色錯選。
- **三色螢光筆題幹高亮**：
  - 💛 **黃色**：核心主旨與關鍵論點
  - 💗 **粉色**：反差映襯與干擾陷阱
  - 💚 **綠色**：解題關鍵破案線索
- **解題之眼・直擊死穴**：每題獨家提煉金色外框命題核心盲點與得分密碼。
- **逐選項正誤破譯**：全面剖析 (A)(B)(C)(D) 選項正誤原理，破除模稜兩可。
- **A4 向量精編 PDF 講義**：嚴格落實「一題一頁、絕無溢出」，適合教師課堂投影與學生紙本複習。
- **支援跨平台多裝置**：適配桌機、筆電、iPad、手機與教室觸控大螢幕。
