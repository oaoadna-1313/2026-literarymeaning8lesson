## 💡 特色亮點

- **純題作答模式**：初始狀態純呈現題幹與選項，無答案干擾。
- **互動即時核對**：點擊選項即時給予答題回饋。
- **擬真螢光筆詳解**：平滑展開精準答題線索高亮、文本詞彙注釋與全文語譯。
- **學習進度追蹤**：支援作答記錄、答對率統計與 LocalStorage 本地儲存。
- **支援跨平台多裝置**：適配電腦、平板、手機與觸控大螢幕投影教學。
